Add a folder

Filewise will read files in this folder. Try a practice folder first; do not select your entire home directory.

Includes subfolders. Keys, tokens, databases, partial downloads and symlinks are always excluded. File scope is fixed after registration.

Analysis & metadata

Local extraction uses document titles, text excerpts, file types and configured JSON fields. It does not claim AI understanding.

When enabled, up to 20,000 characters are sent to this local service. Filewise does not upload to a remote model, download a model automatically or silently switch providers on failure. Make sure the local service itself is trusted.

Naming rules

Supports {title}, {original}, {date}, {category} and {hash}. The date is the first-detected UTC date. Extensions are preserved. Collisions get a safe suffix; existing files are never overwritten.

Detection settings

Stability detection is a safeguard, not proof that a download is complete. Increase the wait for slow downloads. Limits: 10 MiB per file; 1,000 files / 50 MiB per folder.

Processing details

Background & startup

This page is just the interface. The Go background service keeps monitoring. Closing or reopening the page does not erase your rules or history.

Changes take effect at your next login, without administrator access. Keep the executable and data directory in their current locations.

This is a login item, not a crash supervisor. Scanning pauses while the computer is off or asleep, or the service is stopped. Changes made offline are detected after the service resumes.

Connect to local Filewise

Run filewise start to open an authorized workspace. Or paste the token after #token= in the link returned by that command.

This token can edit registered projects, but cannot approve or publish. Do not share token-bearing links.
