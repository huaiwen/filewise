# Filewise

<!-- impeccable:product-schema 1 -->

## Platform

web

This record scopes the public product website in `site/`. The local workbench in `internal/workspace/ui/` is a separate surface. The owner subsequently requested Word demonstrations, semantic change metadata and a Go-first development line.

## Users

People working with local documents and their coding agents, including Codex, Claude Code and Cursor users.

## Product Purpose

A local file workspace shared by people and agents: organize files, preserve versions and retrieve information with its source. The website helps visitors understand the mechanism and find an installation path.

## Positioning

Original files remain in familiar directories. Completed snapshots bind content, metadata and evidence; authorized agents retrieve concrete versions and locations. Working saves and independently reviewed publication are separate operations.

## Operating Context

macOS and Linux. The active `0.3.0-dev` runtime is Go: workspace storage/authorization, HTTP/Agent CLI, monitoring/workbench, document extraction, quality/tasks and independent publication, plus semantic change metadata and a separate document journal. This Go version is not publicly released. The immutable Rust v0.2.0 release remains historical. Node.js supplies npm distribution, not the engine.

## Capabilities and Constraints

- Historical published preview: Rust v0.2.0; its assets remain unchanged. The approved website retains this historical installation link. Current Go distribution refuses legacy fallback and remains unpublished.
- Go runtime: project workspace and scoped Agent gateway, PDF/modern Office/UTF-8 extraction, exact change rules, before/after quotations and immutable originals. Derived `meta.semantic_change` is separate from human metadata. Ambiguous prose or incomplete evidence requires review; downstream impact is not inferred from arithmetic. See `docs/go-migration.md`.
- Text, Markdown, JSON, CSV and text extraction from PDF, DOCX, XLSX and PPTX. No OCR, legacy Office or formula execution. Incomplete extraction is reported.
- Limits: 10 MiB per file; 1,000 files / 50 MiB per folder.
- Project-scoped access; working changes can modify originals. Publication requires separate authority and review.
- npm entrypoint and portable Skills exist locally; npm is not published. Its commands must remain labeled as forthcoming, without copy controls.
- Website is static, bilingual, undeployed and has no document upload, analytics, account, or connection to the local service. Hosting and domain remain undecided.
