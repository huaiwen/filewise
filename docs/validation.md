## 本机环境问题与处理

本机给虚拟环境 `.pth` 文件设置了 macOS `UF_HIDDEN`，CPython 因而跳过可编辑导入。测试先通过 `PYTHONPATH=src` 执行，最终改用 `uv sync --no-editable` 并在独立 wheel 环境复验；未向产品加入 sys.path 修补。

沙箱的默认 uv 缓存目录和网络不可用：缓存改在临时目录，依赖下载经批准开放网络后成功。本地端口监听也在授权的回环地址上完成。一次独立 wheel 离线安装因缓存不全失败，补齐基础依赖后成功。

Starlette 当前版本对 TestClient 使用 HTTPX 输出弃用提示，测试仍全部通过；没有隐藏提示。锁定依赖保留可复现版本。
