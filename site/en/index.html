About Filewise.

Are my files uploaded?

Originals and history stay on your machine by default. Optional model analysis connects to your configured local Ollama. Content given to a cloud agent is subject to that platform's data handling. This website does not read or upload your files.

Which files can I use?

UTF-8 text, Markdown, JSON and CSV, plus text extraction from PDF, DOCX, XLSX and PPTX. Scanned-document OCR, legacy Office and visual-layout reproduction are outside the current scope. Formulas are not executed. Incomplete extraction is reported.

Can an agent edit or publish files?

Read-only credentials allow search and reading. Editor credentials allow authorized working saves, which change originals. Publication requires separate roles, independent review and passing checks.

What are the current limits?

This is a development preview: up to 10 MiB per file and 1,000 files / 50 MiB per folder. Native binaries support macOS and Linux. Native Windows support and local vector retrieval are not available yet.
