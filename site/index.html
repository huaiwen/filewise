下载安装包

安装 Filewise，打开本地工作台。

curl -fsSL https://github.com/huaiwen/filewise/releases/latest/download/install.sh | bash
export PATH="$HOME/.local/bin:$PATH"
filewise start

安装器校验 SHA-256。文件夹由你选择；登录启动单独开启。

关于 Filewise。

文件会被上传吗？

原件与历史默认保存在本机。可选模型分析连接你配置的本机 Ollama。将内容交给云端 Agent 后，该平台的数据处理规则适用；本网站不会读取或上传你的文件。

支持哪些文件？

支持 UTF-8 文本、Markdown、JSON、CSV，以及 PDF、DOCX、XLSX、PPTX 的文本提取。扫描件 OCR、旧版 Office 和视觉版式还原不在当前范围；公式不执行。提取不完整时明确标记。

Agent 能修改或发布文件吗？

只读凭证允许检索与读取；编辑凭证允许授权范围内的工作保存。保存会修改原件，正式发布仍需要相应角色、独立审核和检查结果。

有哪些使用限制？

当前为开发预览：单文件最多 10 MiB，每个文件夹最多 1,000 个文件、50 MiB。原生程序支持 macOS 与 Linux；Windows 原生版和本地向量检索尚未提供。
